# Catalyst Consulting Website

Cayman's Human-First AI Consultancy

## Overview

A modern, responsive website for Catalyst Consulting, showcasing AI consulting services with a focus on human-centered approach. The website features gradient designs, smooth animations, and a mobile-first responsive layout following the brand guidelines.

## Features

- **Modern Design**: Vibrant gradients using brand colors (Quantum Violet, Core Blue, Pulse Cyan, Hyper Pink, Nova Red)
- **Smooth Animations**: Scroll-triggered animations and interactive elements
- **Fully Responsive**: Mobile-first design that works on all devices
- **Interactive FAQ**: Accordion-style frequently asked questions
- **Contact Form**: Functional contact form with validation
- **SEO Optimized**: Semantic HTML and meta tags

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## Installation

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required!

## Deployment

This is a static website and can be deployed to any static hosting service:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Any web server

## Customization

To customize the website:

1. **Colors**: Edit CSS variables in `assets/css/styles.css`
2. **Content**: Update text in `index.html`
3. **Images**: Replace logos in `assets/images/logos/`
4. **Functionality**: Modify `assets/js/main.js`

## Performance

- Optimized images
- Minimal dependencies (no frameworks)
- Debounced scroll events
- Lazy loading for animations
