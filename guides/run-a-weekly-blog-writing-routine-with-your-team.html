Run a weekly blog writing routine with your team

A Trello board that moves each article from idea to published, with automatic reminders and AI help at every stage.

Content & WritingAdvanced45 minTrelloAI assistantGoogle DocsGoogle Calendar

When to use it

Set up once, run every week

Step by step

  1. Build the board

    In Trello, create lists: Ideas, Outline, Drafting, Editing, Ready, Published. Add each article idea as a card with the target keyword in the description.

  2. Add automatic rules

    Use Trello's built-in automation (look for Automation on the board menu) to set rules such as 'when a card moves to Drafting, set a due date 3 days out and add the writer' and 'when a card moves to Ready, add a Publish checklist'.

  3. Use one prompt per stage

    Save stage prompts in a pinned card so anyone can use them. This is the outline prompt; keep similar ones for drafting and editing.

    Prompt to copyCreate an outline for a blog post. Title idea: [card title]. Keyword: [keyword]. Reader: [audience]. Give: 3 title options, an intro hook, 5 H2 headings with 3 bullets each, one place for a real example from us, and a closing call to action to [CTA]. Note any facts we'll need to source.

  4. Draft in linked Google Docs

    Write each draft in Google Docs and attach the link to the card so everything lives in one place.

  5. Hold a weekly 15-minute check

    Set a recurring Google Calendar event to review the board, move cards along and choose next week's ideas.

What you get

Mon: 'How to choose a wood burner' moves to Drafting -> due Thu, assigned to Ellie automatically. Thu: moves to Editing with editor's notes attached. Fri: moves to Ready -> Publish checklist added (images, links, meta description).

Tips

  • Free Trello plans have limits on automation runs; keep rules simple or check your plan if you hit the cap.
