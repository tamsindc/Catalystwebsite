Build a numbered exhibit list for trial in an hour

A tidy, numbered exhibit schedule in a spreadsheet with short descriptions, dates and page counts, ready for checking and the trial bundle.

ParalegalIntermediate45 minAI assistantExcelGoogle SheetsOneDrive
Open the interactive guideBrowse all guides

When to use it

When preparing a hearing or trial bundle

Step by step

  1. List the files you have

    In your document folder, copy the list of file names for the exhibits into a spreadsheet column. Add any notes you already have, such as who produced each one.

  2. Ask for a draft exhibit schedule

    Paste the file list into your firm-approved AI assistant with this prompt. Keep client names out if the tool is not approved for confidential work.

    Prompt to copyHere is a list of exhibit file names and notes for a [type of case] hearing. Create a table I can paste into a spreadsheet with columns: Exhibit number (format [A1, A2...]), Short neutral description (max 12 words), Date of document, Author or source, Number of pages (leave blank if unknown), Party relying on it, Notes. Group by [chronological order / topic / party]. Flag any files that look like duplicates or drafts. Files: [paste list]

  3. Paste it into your spreadsheet

    Paste the table into Excel or Google Sheets, then fill in the page counts and anything marked blank by checking each file yourself.

  4. Rename files to match

    Rename each file to start with its exhibit number so the folder and the list always match, for example 'A3 Inspection report 2024-05-12'.

  5. Get it signed off

    Send the schedule to the supervising lawyer to approve the order, descriptions and anything left out before the bundle is finalised. If the AI mentions any case or law, check it against the original source, as AI can invent case law.

What you get

A1 | Tenancy agreement | 01/09/2022 | [Agent] | 14 pp | Claimant A2 | Email reporting damp | 12/01/2024 | [Client] | 1 p | Claimant A3 | Inspection report | 12/05/2024 | [Surveyor] | 9 pp | Claimant Flag: 'A2 copy final' looks like a duplicate of A2.

Tips

  • Keep descriptions neutral. Ask the AI to avoid words that argue the case, such as 'proves' or 'admits'.
  • Check your court's or firm's bundle rules for numbering and indexing, as they vary.
