Write a checklist for jobs you do again and again

Describe a task you repeat and get a step-by-step checklist anyone can follow, so nothing gets forgotten and others can help.

Planning & ProductivityBeginner10 minAI assistantGoogle DocsNotion
Open the interactive guideBrowse all guides

When to use it

Whenever you notice you're doing the same job for the third time

Step by step

  1. Talk through how you do it

    Type or voice-record yourself explaining the task from start to finish, including the bits you usually forget.

  2. Turn it into a checklist

    Paste your description into your AI assistant with this prompt.

    Prompt to copyTurn my description into a clear checklist for [task] that someone new could follow. Include: what it's for in one line; what you need before starting; numbered steps, each one action starting with a verb; warnings for common mistakes; how to know it's done properly; and how long it usually takes. Use plain words, no jargon. Then list any steps that seem missing or unclear. My description: [paste]

  3. Save and test it

    Put the checklist in a shared Google Doc or Notion page. Next time, follow it exactly and fix anything that's wrong.

What you get

Closing the café on Sundays (20 min). Need: keys, cash bag. 1. Turn off the coffee machine and run the clean cycle. 2. Count the till and record totals in the cash book. 3. Wipe and stack chairs... Warning: Don't switch off the fridge circuit. Done when: alarm is set and green light shows.

Tips

  • Add photos of tricky bits, like which switch to press; they save a lot of explaining.
