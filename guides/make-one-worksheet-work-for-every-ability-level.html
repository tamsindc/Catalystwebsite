Make one worksheet work for every ability level

Three versions of the same worksheet, with support, core and stretch levels, so every pupil can work on the same topic.

TeacherBeginner10 minAI assistantWord
Open the interactive guideBrowse all guides

When to use it

When preparing classwork for a mixed-ability group

Step by step

  1. Start with your existing worksheet

    Copy the text of your worksheet or task. Don't include any pupil names or details.

  2. Ask for three levels

    Paste the worksheet into your AI assistant with this prompt.

    Prompt to copyHere is a worksheet on [topic] for [year group]. Rewrite it in three versions that cover the same learning: 1) Support: simpler wording, sentence starters, a worked example and a word bank, 2) Core: the original level, tidied up, 3) Stretch: fewer hints, one harder question that asks pupils to apply or explain. Keep the questions in the same order so I can teach them together. Add a short answer key for each version. Use clear, accessible language and a dyslexia-friendly layout suggestion. [paste worksheet]

  3. Format and print

    Paste each version into Word or Google Docs, use a clear font and check the answers before printing.

What you get

Support Q2: 'Plants need light to make food. This is called p_________.' Word bank: photosynthesis, chlorophyll, glucose. Core Q2: 'What is photosynthesis?' Stretch Q2: 'Explain why a plant left in a dark cupboard would eventually die.'

Tips

  • Label versions with shapes or colours rather than 'easy' and 'hard' to avoid pupils feeling singled out.
