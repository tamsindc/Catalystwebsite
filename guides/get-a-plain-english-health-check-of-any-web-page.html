Get a plain-English health check of any web page

A friendly report on one page of your website: what's clear, what's confusing, and a short fix list to help it show up in search.

When to use it

When a page isn't getting visits or enquiries

Step by step

  1. Copy the page's words

    Open the page, select all the text and copy it. Also note the page title shown in the browser tab and the main phrase you want it to be found for.

  2. Ask for a review

    Paste the text into your AI assistant with this prompt. Some assistants can read a link directly, but pasting the text is more reliable.

    Prompt to copyReview this web page for a small business. Page title: [title]. Phrase I want it found for: [phrase]. Audience: [who it's for]. Page text: [paste]. Give me: 1) a score out of 10 for clarity and one for search-friendliness, with reasons; 2) whether the main phrase appears in the title, first paragraph and a heading; 3) the three biggest problems a visitor would notice; 4) a rewritten page title (under 60 characters) and meta description (under 155 characters); 5) a numbered fix list, easiest first. Plain English, no jargon.

  3. Make the easy fixes first

    Work through the fix list in your website editor. Most site builders let you change the page title and description in the page's settings or SEO section.

What you get

Clarity 6/10: the first paragraph talks about your history, not what you do. Search 4/10: 'dog grooming Bristol' isn't in the title or headings. New title: Dog Grooming in Bristol | Gentle, Fear-Free Care. Fix 1: Move prices higher up the page.

Tips

  • Re-run it a month after making changes and compare scores.
  • Treat it as a second opinion, not a guarantee of rankings.
