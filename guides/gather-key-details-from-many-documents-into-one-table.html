Gather key details from many documents into one table

Upload a batch of similar documents, like CVs, quotes or proposals, and get one comparison table with the same details pulled from each.

When to use it

When you need to compare a stack of similar documents

Step by step

  1. Put the documents in one folder

    Save them in a Google Drive or OneDrive folder and give each a clear file name.

  2. Decide what to compare

    List the five to ten details you want from every document, such as price, start date and experience.

  3. Extract the details

    Upload the documents to your AI assistant (in batches of about five if there are many) with this prompt.

    Prompt to copyFor each attached document, extract these details: [detail 1], [detail 2], [detail 3], [add more]. Output one table with a row per document and a column per detail, plus a 'File name' column and a 'Notes' column for anything unusual. Copy values exactly as written. If a detail isn't in a document, write 'not stated'. Don't rank or judge them yet.

  4. Paste into a sheet and check

    Copy the table into Google Sheets. Check two or three rows against the original documents before you rely on it.

  5. Compare and decide

    Sort and filter the sheet yourself. The decision is yours; the table just saves the retyping.
